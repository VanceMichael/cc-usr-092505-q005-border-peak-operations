# 口岸高峰勤务编排

编排机场边检高峰期航班、通道、设备和有资质的值守人员。

## 领域资料

`contracts/domain.schema.json` 记录共享资料结构，`fixtures/domain.json` 是不含真实个人信息的示例。参与方包括边检值班长、查验人员、航班保障人员、异常协查人员。

当前资料依据以下业务事实维护：

- 双节期间口岸预计客流同比增长百分之六十三
- 边检根据实时流量调整勤务并增开查验通道
- 旅客证件有效期和材料完整性会影响通关效率

## 后端模块

- `src/clock.js` 可注入时钟（系统时钟/固定时钟），跨午夜班次与峰值一律按绝对毫秒计算
- `src/model.js` 航班版本、预计/实际旅客量、入出境方向、通道与智能设备能力、人员资质、班次休息约束的结构校验，以及客流需求与峰值计算
- `src/planner.js` 按资质、班次窗口、连续执勤上限把人员填入槽位岗位，输出应急预留与缺口
- `src/service.js` 计划发布与事件修订：航班改时、设备停用、岗位换班、加急协查只修订未执行时段，已开始勤务保留原安排与交接记录；命令按 revision 乐观并发（拒绝较晚版本）、航班更新按版本幂等（重复保持原结果）；证件材料按授权检查范围过滤；交班摘要（开放通道、下一时段缺口、临时调整依据、未处理异常）在同一读取水位生成

`test/peak.test.js` 用固定航班与固定时钟重放一次完整高峰，不接入真实机场设备。

## 开发命令

- 运行测试：`npm test`
- 编译或构建：`npm run build`

上述命令只读取仓库内文件，不连接外部业务服务。
